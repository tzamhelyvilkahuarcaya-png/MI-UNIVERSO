EXPLORA EL UNIVERSO - VERSION NAVEGABLE

1. Extrae todo el contenido del ZIP en una carpeta.
2. Abre index.html.
3. Pulsa "Explorar planetas".
4. Pulsa cualquier planeta.
5. Dentro de cada planeta puedes:
   - Ver información del planeta.
   - Ver sus lunas.
   - Pulsar "Anterior" y "Siguiente".
   - Volver a "Todos los planetas".
   - Volver a "Inicio".

No necesitas instalar ningún programa. Funciona abriendo index.html en un navegador.
